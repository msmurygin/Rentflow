# Приватность и данные (закрытая бета)

Краткий текст для людей — команда бота `/privacy`. Здесь — полный.

## Что хранится
| Данные | Где | Зачем |
|---|---|---|
| Telegram-ID, имя из Telegram | `app_user`, `api_session` | вход, роли, отправка сообщений |
| Название/адрес квартиры, имя арендатора (вводит владелец) | `property`, `tenancy` | счёт и интерфейс |
| Показания, фото счётчиков, тарифы, счета, оплаты | `reading`, `bill`, `tariff`, каталог фото | расчёт; счета неизменяемы после утверждения |
| Журнал действий (кто, что, когда; без текста сообщений) | `audit_log` | расследование споров, метрики |
| Неудачные доставки в Telegram (только код причины) | `notification_log` | диагностика |

Не хранятся: телефоны, e-mail, платёжные реквизиты, тексты сообщений бота.

## Кто видит
Только участники этой квартиры (владелец, арендатор). Чужая квартира/счёт/фото отвечает 404, как несуществующие.
Администратор сервиса технически имеет доступ к базе; он не читает данные без нужды (поддержка, расследование сбоя).
Демо-квартира (`telegram_id < 0`) — вымышленная, только для чтения, в метриках не учитывается.

## Третьи лица
- Telegram — переносит сообщения и открывает Mini App.
- Anthropic API — получает **фото счётчика** для распознавания, если задан `ANTHROPIC_API_KEY`. Без ключа фото не уходят,
  показания вводятся вручную.
- Hetzner — хостинг; резервные копии шифруются `age` до выгрузки за пределы сервера.

## Сроки хранения
- Счета, показания и оплаты — пока владелец ведёт квартиру (это учётные данные расчётов между людьми).
- Сессии Mini App — 7 дней; демо-сессии — 6 часов.
- Резервные копии — `BACKUP_RETENTION_DAYS` (30 по умолчанию).

## Выгрузка и удаление
Автоматической кнопки нет (бета). По запросу человека администратор:
1. выгружает его квартиры, показания и счета (SQL по `property_id`);
2. удаляет квартиру целиком по просьбе владельца **после того, как стороны сохранили нужные им счета**;
3. записывает запрос и выполнение в `audit_log`.
Удаление из резервных копий происходит по истечении срока их хранения.
Автоматизация выгрузки/удаления — вне объёма v0.3.
